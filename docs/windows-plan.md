# Windows 支持计划（未实施）

本次仅为 Linux 与 macOS 实施。没有 Windows 后端、PowerShell 安装器、注册表写入、UAC 助手、Windows 构建作业或安装包。

## 共用界面

保持相同首页、清理结果、空间分析、卸载和启动项页面；通过后端能力说明可用范围。不新增 Windows 专属配色或导航，不把不存在的功能显示为成功。

## 适配顺序

1. Windows 10/11、x64 与 ARM64 的 Tauri/WebView2 原生构建和窗口行为；MSI/NSIS 安装、升级与卸载。
2. 使用 Known Folders 获取下载、文档、图片、视频、桌面路径；缓存规则以应用为单位，文件清理使用系统回收站。
3. 从用户/系统卸载注册表和 MSIX inventory 枚举应用；Winget 管理应用与更新。卸载只调用已登记的程序，需校验参数和签名，不对卸载字符串直接执行任意 shell。
4. 管理用户 Startup 目录、Run 键及用户启动任务；系统任务先只读。保留禁用状态与恢复能力。
5. 注册系统服务或签名助手承接固定特权操作。UAC 授权仅使用系统机制；不保存管理员密码，不跨重启建立免授权访问。
6. 增加 MSVC 构建、回收站恢复、重解析点/符号链接、锁定文件、长路径、中文用户名、权限拒绝与取消授权等验收。

## 清理边界

不直接删除 WinSxS、Windows Installer、Windows Update 数据或 ProgramData 整体目录；系统清理由对应系统接口处理。应用缓存规则先扫描和解释，再由用户选择执行。浏览器账号数据、业务数据库和应用文档不默认清理。

## 完成条件

真实 Windows 设备上完成安装、扫描、选择清理、恢复、卸载、启动项切换、更新、授权取消/过期等流程后，才将支持状态从“计划”改为“支持”。
