# 平台支持与验收

更新日期：2026-10-13（Asia/Shanghai）。

Linux 与 macOS 共用页面和 IPC，分别适配包管理器、目录和启动机制。Windows 只规划。

以下各节记录对应版本的实施与实测快照；最新状态以最后的“能力强化与监控”节为准，旧测试数量、浏览器连接情况和界面描述不是当前验收结论。

## 本次实施

- 主窗口、清理结果及工具页面采用原创深紫界面、紫青轨道视觉与常驻导航；清理结果可展开文件名、路径、大小并查看文件位置。早期 Lemon 外观已替换。
- 系统规则和容器垃圾纳入垃圾扫描，使用同一个选择列表和清理按钮。移除独立的系统诊断/空间占用检查列表；目录分析仅保留逐层占用功能。
- Linux APT、journal、tmpfiles 通过专用管理助手扫描和执行固定命令；显示候选文件及大小，未知显示失败。Docker 显示本地守护进程可回收估算，不包含数据卷，选中后执行对应 prune。
- 清理页支持主动管理员授权。Linux 打包独立助手，系统认证安装/更新与短期会话授权；macOS 打开隐私设置。授权失效重新认证，不保存密码。
- 开发者垃圾包括声明式工具缓存规则与手动指定项目目录的深度扫描，保留天数可调，默认不勾选，清理前核对元数据、年龄和可见进程路径。
- 应用卸载列表显示 Linux 本地图标或 macOS 应用包图标，缺失/加载失败时显示统一占位图标。
- 脚本适配 Linux / macOS 安装与构建，CI 配置两个平台的原生检查；未添加 Windows 实现。

## 2026-10-13 能力强化与监控

- 应用卸载增加来源覆盖状态、可靠缓存/启动项/已检测更新关联、依赖影响预览和串行队列。Toolbox 的 IDE、缓存与入口选择联动，个人配置默认保留；实际安装状态回读同步连带卸载。预览有期限及身份复核，范围变化拒绝执行。RPM 与复杂 Homebrew 安装仅提供原渠道建议；Snap 遵循渠道的数据处理规则。
- 文件工具支持多根目录、持久保留名单、大文件门槛与开发者保留时间。执行时重新读取最新保留名单，命中受保护子路径的整体目标保留；系统动作无法确认避开名单时跳过。目录分析包含叶子文件，根目录与排除路径统一解析，不跟随子符号链接、不跨文件系统。
- 扫描与检测纳入任务中心，显示阶段、数量和路径，协作取消保留已发现结果；外部查询可能等待有界超时。已开始的处理不中断，卸载/升级队列支持停止后续。清理逐项反馈成功、失败及跳过，失败可重试。任务与最近结果仅限本次会话，不提供退出后的队列恢复。
- 开发产物按来源项目归组并提示重建影响，重复文件可指定保留副本后选择其余。后端再次确认有效保留副本、原始文件指纹和有效扫描范围。
- 更新报告记录每个渠道的检测状态、时间和缓存；串行队列提供目标版本、架构、日志、失败重试。同名多架构按确认身份唯一匹配，成功回写保留其他架构，旧请求无法唯一确认时拒绝。APT/DNF4 使用共享计划与管理员助手锁定确认版本，Flatpak 锁定范围、完整 ref 和 commit；可靠 npm/uv/pipx 实例限定公开原来源与安装实例、10 分钟许可、执行前复核和执行后版本回读。Homebrew/YUM/Zypper/DNF5 无可靠精确版本锁时转原渠道建议，Arch 要求完整升级。
- 新增第 10 个页面“本机监控”与应用内底部状态栏。默认可关闭的 2.5 秒 CPU/内存采样，磁盘每 30 秒刷新，窗口隐藏时暂停定时采样，最多保留 60 次会话曲线；资源采样关闭后任务中心仍可用。Linux 首次 CPU 未知，内存按总量减可用量；Mac 内存包含可回收缓存，不等同于压力。没有系统托盘、浮球、自动告警或进程终止。
