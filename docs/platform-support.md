# 平台支持与验收

日期：2026-10-12（Asia/Shanghai）。

Linux 与 macOS 共用页面和 IPC，分别适配包管理器、目录和启动机制。Windows 只规划。

## 本次实施

- 参考 Lemon Cleaner 统一主窗口、清理结果及工具页面，采用白色背景、绿色操作、橙色统计；清理结果可展开文件名、路径、大小并查看文件位置。
- 系统规则和容器垃圾纳入垃圾扫描，使用同一个选择列表和清理按钮。移除独立的系统诊断/空间占用检查列表；目录分析仅保留逐层占用功能。
- Linux APT、journal、tmpfiles 通过专用管理助手扫描和执行固定命令；显示候选文件及大小，未知显示失败。Docker 显示本地守护进程可回收估算，不包含数据卷，选中后执行对应 prune。
- 清理页支持主动管理员授权。Linux 打包独立助手，系统认证安装/更新与短期会话授权；macOS 打开隐私设置。授权失效重新认证，不保存密码。
- 开发者垃圾包括声明式工具缓存规则与手动指定项目目录的深度扫描，保留天数可调，默认不勾选，清理前核对元数据、年龄和可见进程路径。
- 应用卸载列表显示 Linux 本地图标或 macOS 应用包图标，缺失/加载失败时显示统一占位图标。
- 脚本适配 Linux / macOS 安装与构建，CI 配置两个平台的原生检查；未添加 Windows 实现。
